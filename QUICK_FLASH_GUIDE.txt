GTA4XLVE KernelSU - Quick Flash Guide
===============================================

🚀 FASTEST WAY TO FLASH
-----------------------

**For LineageOS Users (No TWRP needed!):**
1. Download: gta4xlve-ksun-YYYYMMDD.zip
2. Boot to LineageOS Recovery (Vol Up + Power)
3. Navigate with Volume buttons, select with Power
4. Go to: Apply update → Apply from ADB
5. Run on PC: adb sideload gta4xlve-ksun-YYYYMMDD.zip
6. Reboot and install KernelSU Manager app

**For TWRP/OrangeFox Users:**
1. Download: gta4xlve-ksun-YYYYMMDD.zip
2. Boot to Recovery (Vol Up + Power)
3. Install ZIP in TWRP/OrangeFox
4. Reboot
5. Install KernelSU Manager app

📋 REQUIREMENTS
--------------
✓ Unlocked bootloader
✓ LineageOS Recovery OR TWRP/OrangeFox
✓ Device: SM-P610 or SM-P613 (GTA4XLVE)
✓ Android 11-16 (incl. QPR2) / LineageOS 18-23 (incl. 23.2)
✓ Backup your data!
✓ ADB tools (for LineageOS Recovery method)

🔧 WHAT'S FIXED
--------------
✓ Proper AnyKernel3 script with shebang
✓ Correct boot partition location
✓ Device-specific boot header (v2)
✓ Android 11-14 compatibility check
✓ LineageOS Recovery support

----------------

⚠️ TROUBLESHOOTING
------------------
Bootloop? → Flash in recovery, wipe cache
No root? → Install KernelSU Manager app
Won't boot? → Dirty flash your LineageOS ROM
LineageOS: No need for TWRP - use built-in recovery!

💡 TIPS
-------
• LineageOS users: Use built-in recovery with ADB sideload
• TWRP optional - LineageOS Recovery works great!
• Keep your ROM ZIP as backup
• KernelSU ≠ Magisk (different modules!)
