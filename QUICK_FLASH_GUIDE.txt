GTA4XLVE KernelSU - Quick Flash Guide
===============================================

🚀 FASTEST WAY TO FLASH
-----------------------

**For LineageOS Users (No TWRP needed!):**
1. Download: gta4xlve-ksun-YYYYMMDD.zip
2. Boot to LineageOS Recovery (Vol Up + Power)
3. Navigate with Volume buttons, select with Power
4. Go to: Apply update → Apply from ADB
5. Run on PC: adb sideload gta4xlve-ksun-YYYYMMDD.zip
6. Reboot and install KernelSU-Next Manager app

**For TWRP/OrangeFox Users:**
1. Download: gta4xlve-ksun-YYYYMMDD.zip
2. Boot to Recovery (Vol Up + Power)
3. Install ZIP in TWRP/OrangeFox
4. Reboot
5. Install KernelSU-Next Manager app

📲 WHICH MANAGER APP?
---------------------
⚠️  IMPORTANT: Use KernelSU-Next Manager!

Download: https://github.com/rifsxd/KernelSU-Next/releases
Version: Any latest v1.x.x APK

❌ DON'T USE: Original KernelSU Manager (tiann)
   - Incompatible with KernelSU-Next
   - Will show "unsupported"

✅ USE: KernelSU-Next Manager (rifsxd)
   - Made for KernelSU-Next
   - Works with legacy branch
   - Shows version 32956+

See MANAGER_VERSION.md for full details!
